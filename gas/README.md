# 線上訂單串接 Google Sheet（Google Apps Script）

網站的「送出訂單」會把訂單寫進 Google 試算表。目前不寄任何信件，所有訂單只記錄在試算表。

## 架構

```
網站結帳表單 ──POST──▶ Apps Script 網頁應用程式（gas/Code.gs）──▶ Google 試算表
     ▲                         │                                   ├ 訂單
     └──GET ?action=menu───────┘                                   ├ 訂單明細
        （同步價格、售完）                                          ├ 菜單（改價、勾選上架）
                                                                    ├ 門市（各店通知信箱）
                                                                    └ 每日報表
```

## 安裝步驟（約 10 分鐘）

1. 建立一個新的 Google 試算表，命名例如「Maison Doré 訂單」。
2. 上方選單 **擴充功能 → Apps Script**，把 `gas/Code.gs` 的內容全部貼上取代，按儲存。
3. 回到試算表重新整理，上方會出現 **Maison Doré** 選單：
   - 按 **① 初始化工作表**（第一次會要求授權，請同意）
   - 按 **② 安裝每日報表排程**
   - 按 **建立一筆測試訂單**，確認「訂單」工作表多一筆
4. 回到 Apps Script，右上角 **部署 → 新增部署作業**：
   - 類型：**網頁應用程式**
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   - 按部署，複製「網頁應用程式網址」（`https://script.google.com/macros/s/.../exec`）
5. 打開 `index.html`，找到這行，貼上網址：
   ```js
   const ORDER_API = '';
   ```
6. 推上 GitHub 後，網站就會開始真的接單。

> 之後修改 Code.gs，要用 **部署 → 管理部署作業 → 編輯 → 版本：新版本** 重新部署，網址不變。

## 日常操作

| 想做的事 | 怎麼做 |
|---|---|
| 改價格 | 改「菜單」工作表的「單價」，網站下次開啟自動更新，結帳也以此價格計算 |
| 品項售完 | 取消「菜單」工作表該品項的「上架」勾選，網站按鈕會變成不可點 |
| 更新訂單進度 | 把「訂單」的「狀態」改成 製作中／可取餐／已完成 等（不會寄信） |
| 每日營收 | 每晚 22:00 自動記錄在「每日報表」，也可從選單手動產生 |
| 查詢訂單（API） | `網址?action=status&no=訂單編號&phone=手機` |

## 安全與可靠性設計

- **價格以試算表為準**：網站送來的價格一律忽略，由伺服器重新計算小計、運費與總額。
- **不重複下單**：每筆訂單帶有隨機請求 ID，網路重送不會建立兩筆。
- **離線暫存**：顧客網路中斷時，訂單暫存在手機，恢復連線後自動補送。
- **防灌單**：同一支手機 10 分鐘內最多 5 筆；表單有隱藏的機器人陷阱欄位。
- **防公式注入**：以 `=`、`+`、`-`、`@` 開頭的文字會加上 `'`，避免被試算表當成公式執行。
- **同時下單不衝突**：使用 LockService 排隊寫入，訂單編號依日期流水號（MD251127-0001）。

## 設定（Code.gs 最上方 CFG）

- `FREE_SHIP` / `SHIP_FEE`：宅配免運門檻與運費（需與網站一致）
- 寄信開關（目前全部 `false`）：`SEND_STORE_EMAIL` 新訂單通知店家、`SEND_CUSTOMER_EMAIL` 顧客確認信、`SEND_STATUS_EMAIL` 狀態變更通知、`SEND_REPORT_EMAIL` 每日報表信；要恢復某一種改成 `true` 並重新部署
- `NOTIFY_EMAIL`：開啟寄信時的店家信箱（留空 = 部署者）
- `REPORT_HOUR`：每日報表時間
- `STATUSES`：訂單狀態清單

## 限制

- 若重新開啟寄信：Gmail 免費帳號每天約可寄 100 封信（Workspace 約 1,500 封）。
